# VM Template for VCF9

This project contains a set of scripts to create a VM template for VCF9. 
Includes:

- [AlmaLinux 9](https://repo.almalinux.org/almalinux/9.6/isos/x86_64/AlmaLinux-9.6-x86_64-minimal.iso)
- [AlmaLinux 10](https://repo.almalinux.org/almalinux/10/isos/x86_64/AlmaLinux-10.0-x86_64-minimal.iso)
- [Ubuntu 22.04](https://releases.ubuntu.com/jammy/ubuntu-22.04.5-live-server-amd64.iso)
- [Ubuntu 24.04](https://releases.ubuntu.com/noble/ubuntu-24.04.3-live-server-amd64.iso)
